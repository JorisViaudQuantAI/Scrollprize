# B25 — learned depth-score combiner (development test)
Use only B21 hash-pinned 1447 prediction/label archive; two same-parent windings, 6 crops each, 4 mixed and 2 known-blank. No score inspection for selecting crops (B21 aggregate results known). For each held winding fit only the other winding. Compare two fixed feature models: D = center, median, minimum, maximum, range across three FP32 reverse depth bands; DO = D plus opposite-order center and center-minus-opposite. No spatial coordinates/held data used. StandardScaler and L2 logistic C=1, max_iter=500, sample weight equal total per training crop (weights sum to number of known train pixels); no class rebalance or hyperparameter sweep. All labels >0, unknown excluded. Fit 6 leave-one-source-crop-out models per feature set and calibrate threshold on pooled out-of-fold positives to >=80% recall. Then refit full source winding, apply same threshold to held winding; explicitly report source score-shift from refit and note the threshold is not guaranteed to preserve recall on new data. Report all per-winding AP, recall, FPR, blank FPR and calibration realized recall. Compare center and median3 at thresholds from all source positives (B21). Advancement only if >=2pp held FPR reduction and <=2pp recall loss relative to center for both windings, and no more than 2pp worse recall vs median3 on either; not independent validation. Fit and save full-source models on pooled 1447 with leave-one-crop-out calibration (12 folds), for future distinct-parent evaluation on 0841; no 0841 scores available at freeze. Save exact scaler/coefficients/intercept and thresholds as JSON, no pickle. Predeclare test of both orientation hypotheses using raw Reader scores from B22 if full panel passes preflight. No production deployment, no new labels or model inference. Synthetic check feature orientation, labels never used on held crops, threshold ties. CPU local.
