# B27/B29 fixed local methods
B27: identical B20 scenes and seed cohort, no geometry outcome adaptation. Full 15x15 bidirectional ZNCC baseline (forward .6/.1). Four 8x8 one-sided spatial quadrants including the center (uniform weights, offset origin -3/+4 in each axis). Per-quadrant compute original 8-depth ZNCC in both orders, require forward and backward best opposing signed shift, both corr>=.8, margins>=.12. Candidate rescue only where original m15 fails; require >=2 qualified quadrant votes for same shift and no qualified vote for another shift, plus 5x5 bidirectional corr>=.6, margin>=.1 matching that shift. Compare m15 and m15+rescue; report independently base and rescue counts, all five original scenes, seams, decoys, same gate as protocol. This uses directional support avoiding smoothing across breaks, not yet actual fiber constraints. Separate tensor primitive: gradient structure tensor on synthetic smooth plane (known normal), report orientation error and anisotropy; no claim of actual native normals.
B29: fixed score functions on actual B21 arrays: original center, median3, median3 followed by 3x3 median filter, median3 multiplied by normalized 3x3 local mean, median3 followed by 3x3 min (erosion), median3 combined with maximum length-5 oriented local line average (4 orientations; average of original and max line mean). Calibrate each score function on other winding's known positives to >=80% recall. No target labels for score generation. Score all identical central pixels, including boundaries via nearest extension. Compare held recall/FPR, counts and blank controls. Synthetic topology tests: inject thin open C-shapes and straight lines widths 1,2,3 on actual blank crop score backgrounds; raise stroke to fixed .65, keep background <=.30 by clipping, evaluate at .5, count connected gap bridge using specified open aperture and stroke recall. This is a mechanism stress, not actual letters. Retain baseline maps; pass if >=2pp FPR reduction with <=2pp recall loss both held windings, synthetic stroke recall >=95% for each width and no aperture FP (not a production gate).
