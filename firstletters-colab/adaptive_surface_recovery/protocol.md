# Frozen experiment v1: anchored surface recovery (Q9/Q33/Q15)

Date: 2026-11-23. Branch: chatgpt/adaptive-surface-recovery.

**Source:** Codex's already-published PHerc. 0813 24-site paired geometry receipt, branch commit 1ed75191bbef1c0fa7834c1249f4b0bb8c0eaeaf, path registration-checks/atlas-0813/paired/geometry.json, Git blob SHA1 3e6d227294ad5d8020554a959e1a1494a427c95e. The existing report's 9/23 raw-frame nearest-crest changes are known. Schema and one example record were inspected; this is not a blind or independent scroll validation. No new CT data or ink maps are used.

**Task A (algorithm):** determine whether an anchored bounded-jump depth path improves on independent argmax in a deterministic 41-column simulation. Use every source site with >=2 distinct crests and an unambiguous initially nearest raw crest. Synthetic scores are Gaussian ridges at published crest offsets, with a common sinusoidal shift, varying ridge amplitude, and fixed seeded noise. Three fixed challenges: competing ridge, seven-column target outage, approaching competing ridge. Evaluate columns 1–40 (exclude the known anchor). Dynamic programming optimizes sum of scores minus 0.15 per half-voxel step; max one voxel per column. Reject low score <0.35 or competing global path within 1 score unit outside ±1 voxel. Compare independent argmax at the same score cutoff. Gate, separately per challenge: >=50% acceptance, >=90% accepted within one voxel, zero accepted errors >2 voxels. This is an engineering stress test, not a measure of sensitivity or a physical sheet guarantee.

**Task B (real measured geometry):** on the same public record, evaluate a predeclared raw-ray displacement guard against the distinct tilted snapped-UV ray endpoint (whether the closest crest to the snapped center is also the uniquely closest crest in 3D to the original fixed landmark). Exclude ambiguous or missing endpoint sites, report all exclusions. Baselines: no guard and global displacement cap 4 voxels. Local guard requires predicted center within 2 voxels of the original nearest raw crest and raw competitor distance minus target distance >=2 voxels. Report acceptance, mismatches, and fixed-landmark nearest-crest distance >2 voxels. Gate: >=50% acceptance and zero accepted mismatches. Do not claim the landmark is actual ink or correct anatomical sheet. The paired endpoint is not an independent ground truth. No threshold revisions after observing the outcome.

**Reproduction:** Node.js 18+; download the pinned receipt using git or GitHub and run node firstletters-colab/adaptive_surface_recovery/run.mjs /path/to/geometry.json. The source blob SHA1 must match the pinned value (git hash-object). No network inside the runner, no external dependencies, no model weights. Public results contain aggregate geometry only. The intended next consumer is the existing Codex/Gemini snapping workflow, conditional on new contiguous known-surface validation.
