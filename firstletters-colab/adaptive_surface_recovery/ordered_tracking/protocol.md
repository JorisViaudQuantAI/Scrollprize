# Adaptive 054 — exact ordered multi-surface graph cut and seismic-style DTW

Frozen after 053 instance-separation comparison, before computing any new section, trace, seed, or tracking outcome. Distinct endpoint: track multiple actual manually labeled sheets from a single annotated transverse seed ray, using only CT elsewhere (no GT union mask). Inspired by Li et al. TPAMI 2006 doi:10.1109/TPAMI.2006.19 (ordered coupled surfaces via s-t cut) and Jin et al. JGE 2017 doi:10.1088/1742-2140/aa7309 (seismic waveform matching). Not a reproduction of their complete methods; exact discrete ordered 2D restriction and a basic adjacent-trace DTW baseline. Reuse official 053 source reader and exact SHA256 NRRD bytes from its receipt, same two fixed test cubes [80:176)^3 and normalization. No training on either test cube, no label or score-based parameter search. 053 outcomes were different endpoint; same-scroll and same-cube development comparison, not unseen-scroll validation.

Selection: determine dominant normal axis in each 96³ CT crop by highest mean squared Gaussian derivative (sigma1, all crop voxels; no labels). For each of the other two axes, fixed slices 24,48,72, transpose remaining axes to make normal depth row and lateral x column. Seed ray column48 only: from its manual IDs select every single contiguous run of a nonzero ID with length>=2 and integer floor midpoint at least4 voxels inside depth array; reject both entries of any pair of seed midpoints less than2 apart (nonoverlap). No seedless or score-directed replacement. Section with <2 anchors is unassessable. Compare 6 planned sections per cube (12 total); report all. Label IDs hidden from solvers beyond seed run centers; only evaluation reads nonseed GT.

Arms, identical seed centers and CT: P independent column template match, I independently regularized graph cut, J joint ordered graph cut, W dtw-python 1.5.3 adjacent trace matching. P/I/J share integer unary costs: 9-point centered CT waveform after mean removal and L2 normalization, cost round(1000*(1-correlation+0.002*|depth-seed_depth|)); zero-norm window has correlation0. Allow depths 4..91. Exact anchor at x48 for I/J (P forced only at seed). I/J mincut on threshold variables x>=t, directed infinite-capacity monotonic arcs, unary differences, symmetric total variation 100 integer cost per voxel, maximum adjacent lateral step4 voxels; J additionally min ordered gap2 voxels via hard arcs across neighboring seed surfaces. Use scipy.sparse.csgraph.maximum_flow (Dinic) and residual reachability; cap H = sum of finite capacities +1, require feasible constraints and energy exactly equals returned mincut + unary constant. Brute-force tiny multi-layer lattice oracle (4 seeded random cost fixtures), crossing counterexample, reflection and exact energy check before real input. W uses published dtw-python library on smoothed (Gaussian sigma1) per-column normalized CT intensity and half-weight derivative, squared Euclidean cost, symmetric2 step, Sakoe-Chiba band8, closed endpoints. Map each source index to rounded median target indices on optimal path; propagate all seeds to adjacent traces in both directions, no extra hard gap. Identity and known interior shifted-waveform synthetic sanity check (nonperiodic signal, tolerated 1 voxel). Preserve coincident/crossed tracks and any unavailable sections rather than fixing after outcome.

Evaluation on all lateral columns excluding ±2 around seed: for each seed's ID, if exactly one nonempty contiguous run at that column, score center distance to floor run midpoint, exact predicted manual ID, other manual-ID hit (not background). If run absent or multiple, report unknown and exclude from common evaluable denominator (do not count as success). All arms score same eligible pairs, including out-of-domain/incorrect estimates; no per-arm filtering. Report within2 rate, correct ID rate, wrong ID rate, background rate, MAE, count of adjacent track pairs with gap<2 and strict crossing, evaluated fraction, and each section result. Section requires >=30 eligible pairs, >=50% eligibility to be considered evaluable; report actual all planned sections and counts. Aggregate pooled counts/MAE per cube, not statistical independence. Require >=2 evaluable sections per cube and >=500 eligible pairs per cube. Fixed J advancement: within2 gains >=.05 vs P and >=.03 vs I OR wrong-ID rate reduction >=.05 vs I, both cubes; also correct ID no worse than I by .03, zero gap violations; compare W separately requiring within2 +.05 vs P and correct ID no worse by .03 on both cubes, no >.01 absolute strict crossing fraction. Any failure no promotion; all methods reported. No external model, GPU or unread data. 100 MiB cap, 6-minute one-shot CPU runner. Do not infer complete 3D sheet recovery from 2D single-seed benchmark.
