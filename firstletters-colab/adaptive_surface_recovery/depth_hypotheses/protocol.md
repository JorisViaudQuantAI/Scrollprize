# Bounded depth-hypothesis triage (Q8/Q33) — frozen retrospective protocol

Question: after the failure of single-best recentering and hard sheet guards, can three candidate depth windows selected from a population of calibration CT profiles cover more of the known injected-offset possibilities than three uniformly spaced windows, with the same inference count? This is a CPU-only *geometry proxy*, not new inference or proof of ink recovery. The previous 0841 source profiles and outcomes are already public; this is retrospective, not blind. No tuning on validation outcomes.

Source: firstletters-colab/depth_recentering/results/results.json, Git blob SHA1 b3137ea8c52d5ac0cb6d66137aa1a4f9e1539a64. It contains 24 native CT trimmed-mean profiles, length 28, from one published PHerc0841 control. Calibration rows 0–1 only (12 cells); evaluation rows 4–5 (12 cells). Each cell contributes offsets d=-8..8, observed band native[8+d:20+d] (12 real planes). Recovery truth is correction -d relative to the original band convention, not an anatomically established ink plane.

Baseline: offsets [-6,0,6], three windows. Method: for candidate d in [-8..8], calculate mean of top three Pearson correlations of observed 12-plane vector against each of the 12 calibration native profiles cropped at [8+d:20+d]. Let weight = exp((score - maxScore)/0.10). A constant observed profile is uninformative, use equal weights. Choose three distinct correction offsets from [-8..8] to maximize summed weights within ±1 of any chosen correction (ties: smallest squared offsets, then lexicographic). No validation profile or truth is used by selection. Comparator: single best correlation, with nearest-zero tie. Uniform triplet, adaptive triplet, and single best are all scored with distance to the nearest proposed correction; do not use truth to select an actual production render.

Primary: fraction within one plane (all 204 held-out transformed cases), per-cell and per-offset results; secondary within two planes, mean and maximum distance, uniform/adaptive paired wins and losses. Require adaptive ≥10 percentage points improvement over fixed three windows within 1 plane, ≥90% within 2, no decline >10 points within 1 plane on any of the twelve cells. Gate only authorizes a fresh real model comparison, not deployment. No pixel/letter metrics, no independent scrolls, no false-positive claims, no GPU. Twelve correlated cells, 17 transformed cases each. Source CT acquisition inaccessible from current environment; use archived profiles exactly. A three-window budget is only a proxy for equal inference count; actual rendering/inference costs may vary.

If gate fails, do not tune it on these cells. Report all cases and pivot to another question.
