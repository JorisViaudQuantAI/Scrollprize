# B12b — sparse reference-label intervention stress test

Follow-up to completed B12. Same four public PHerc0211 charts, all 8 verified code grids, common nonzero support, cost arm U=2. This is an idealized paired anchor *label* experiment, not actual fibre extraction or CT-based prediction. At sampled sites observe only signed unary benefit d=C_fitted-C_snap. No full reference codes available to the predictor beyond these sites; full grids used only for scoring. Sampling from common valid support is an optimistic assumption.

For each winding and 32 deterministic seeds (0..31, seed derived from winding index), uniform sample without replacement, nested budgets 16,64,256. For each budget corrupt 0,10,25% of anchor labels by sign inversion at nested randomly chosen indices (floor(rate*n)); actual changed count may be smaller because zero deltas stay zero. Use same anchors for all policies and corruption rates. Hold out all vertices within Euclidean index distance <=2 of any anchor (including anchors); all comparator scores on same held-out population. Distances in grid index units, not physical units.

Fixed policies: always snap, global sign of mean sampled d, nearest-anchor sign, 8-neighbour inverse squared distance interpolation, and Potts graph cut using the latter's estimated d rounded to hundredths, pairwise switch cost 100 (=1 original unary unit). Ties choose snap for sign policies, graph-cut tie choice by residual reachability. No tuning, no score-driven choice, no new reference/ink claims. Report per run count of held vertices, near/far/unresolved counts, unary cost vs always snap, switches on full prediction grid; separately report mean gain and harm rate per winding/budget/noise/method. Primary endpoint lower unary cost on held-out vertices vs snap. Preserve all failure cases. Tests: constant and exact anchor IDW, no held-out leakage by modifying hidden labels, source hashes and graph-cut flow equality. CPU locally; independent seeds are Monte Carlo sensitivity, not independent papyri.
