# Frag5 source and rendering contract

The [contract report](FRAG5_SOURCE_CONTRACT.md) and
[URL/hash manifest](source_contract_manifest.json) preserve the completed
metadata/code audit. The report is copied unchanged, so its recorded hash
continues to identify its exact bytes. Raw source-code downloads and GitHub
API responses remain outside this repository; the manifest identifies those
inspected files rather than claiming they are included here.

The report's references to the companion header/geometry execution correspond
to [the published header bundle](../frag5_headers/README.md). They do not
refer to a private dataset. All inspected surfaces are public, already-opened
fragment controls.

**From the audit records:** no CT intensities, label/photographic pixels,
PSD payloads or model outputs were accessed by this source-code lane.
The report's radius-32/interval-1 mapping is a candidate for numerical
verification, not authenticated Frag5 rendering provenance. The supplied
fine/coarse window metadata does not establish calibrated attenuation, and
the exact Naples annotation lineage remains unresolved.

**My inference:** use the subsequent separately published CT protocol and
its result to determine what was actually verified. These documents are
inputs to that experiment, not an ink-detection result or prize claim.
