# Static follow-up on the failed surface-render contract

The [reaudit report](vc226_sampling_chain_reaudit.md) and its
[receipt](vc226_sampling_chain_reaudit_receipt.json) are copied unchanged.
They inspect the pinned VC 2.26.0 source chain after the measured stage-1
failure. No new experimental pixel, fitted radius, phase or intensity mapping
was used. The source's TIFF loader makes local native-TIFF/Zarr fidelity a
useful separate question.

The [supplemental source receipt](source_supplement/acquisition.json) records
four additional upstream code files and their hashes. Those source-code
bodies remain outside this repository; only descriptions, references and
receipts are bundled here. The report's counterexamples to a file-count
inference are possible code behavior, not claims about the actual Frag5
rendering history.
