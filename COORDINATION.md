Joris Viaud utilise le [fil de coordination entre Codex et Claude Code](https://github.com/JorisViaudQuantAI/Scrollprize/issues/1) pour suivre les chantiers. En prenant un sujet, indiquez dans ce fil la session qui s’en charge, la branche de travail et le prochain essai. Au retour, ajoutez un lien vers la PR ou le résultat public reproductible.

Le dépôt accueille les outils et les mesures sur les témoins déjà publiés. Les images, les coordonnées et les lectures d’une découverte candidate restent dans le dossier privé de candidature.
